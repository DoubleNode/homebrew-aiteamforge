/// A generic repository for managing persistent data.
///
/// `DNSRepository` provides a complete CRUD (Create, Read, Update, Delete)
/// interface for any model conforming to `Identifiable` and `Codable`.
///
/// ## Overview
///
/// Use `DNSRepository` as a base class for your custom repositories:
///
/// ```swift
/// final class UserRepository: DNSRepository<User> {
///     // Inherits all CRUD operations
///     // Add custom business logic as needed
/// }
/// ```
///
/// The repository handles:
/// - Asynchronous operations
/// - Error handling
/// - Data persistence
/// - Cache management
///
/// ## Topics
///
/// ### Creating a Repository
/// - ``init(storage:cache:)``
///
/// ### Fetching Data
/// - ``fetch(id:)``
/// - ``fetchAll()``
/// - ``search(matching:)``
///
/// ### Saving Data
/// - ``save(_:)``
/// - ``saveAll(_:)``
///
/// ### Deleting Data
/// - ``delete(id:)``
/// - ``deleteAll()``
///
/// ### Error Handling
/// - ``RepositoryError``
///
/// ## See Also
/// - <doc:GettingStarted>
/// - <doc:CreatingRepository>
open class DNSRepository<Model: Identifiable & Codable> {

    // MARK: - Properties

    /// The storage layer for persistence.
    ///
    /// The repository delegates all storage operations to this layer.
    public let storage: any StorageProtocol

    /// Optional cache for performance optimization.
    ///
    /// When provided, the repository caches fetched models to reduce
    /// storage access.
    public let cache: (any CacheProtocol)?

    // MARK: - Initialization

    /// Creates a new repository with the specified storage and cache.
    ///
    /// - Parameters:
    ///   - storage: The storage layer for data persistence.
    ///   - cache: Optional cache for performance optimization.
    ///
    /// - Returns: A configured repository instance.
    ///
    /// ## Example
    ///
    /// ```swift
    /// let storage = UserDefaults.standard
    /// let cache = MemoryCache()
    /// let repository = UserRepository(
    ///     storage: storage,
    ///     cache: cache
    /// )
    /// ```
    public init(
        storage: any StorageProtocol,
        cache: (any CacheProtocol)? = nil
    ) {
        self.storage = storage
        self.cache = cache
    }

    // MARK: - Fetching

    /// Fetches a model by its unique identifier.
    ///
    /// This method first checks the cache (if available), then queries
    /// the storage layer if the model is not cached.
    ///
    /// - Parameter id: The unique identifier of the model to fetch.
    ///
    /// - Returns: The requested model.
    ///
    /// - Throws:
    ///   - `RepositoryError.notFound` if no model exists with the given ID.
    ///   - `RepositoryError.storageFailed` if the storage operation fails.
    ///
    /// ## Performance
    ///
    /// When cache is enabled:
    /// - Cache hit: O(1)
    /// - Cache miss: O(n) where n is storage lookup complexity
    ///
    /// ## Example
    ///
    /// ```swift
    /// do {
    ///     let user = try await repository.fetch(id: "123")
    ///     print("Found: \(user.name)")
    /// } catch RepositoryError.notFound {
    ///     print("User not found")
    /// } catch {
    ///     print("Error: \(error)")
    /// }
    /// ```
    ///
    /// ## See Also
    /// - ``fetchAll()``
    /// - ``search(matching:)``
    open func fetch(id: Model.ID) async throws -> Model {
        // Implementation
    }
}
```

**Migration Guide: 1.x → 2.0**

```markdown
# Migration Guide: DNS Framework 2.0

This guide helps you migrate from DNS Framework 1.x to 2.0.

## Overview of Changes

DNS Framework 2.0 introduces:
- ✅ Swift concurrency (async/await)
- ✅ Improved error handling
- ✅ Enhanced type safety
- ⚠️ Breaking API changes

**Estimated migration time:** 2-4 hours for typical projects

## Breaking Changes

### 1. Async/Await Migration

**Before (1.x):**
```swift
repository.fetch(id: "123") { result in
    switch result {
    case .success(let user):
        print(user.name)
    case .failure(let error):
        print(error)
    }
}
```

**After (2.0):**
```swift
do {
    let user = try await repository.fetch(id: "123")
    print(user.name)
} catch {
    print(error)
}
```

### 2. Error Type Changes

**Before (1.x):**
```swift
enum RepositoryError: Error {
    case error(String)
}
```

**After (2.0):**
```swift
enum RepositoryError: Error {
    case notFound(id: String)
    case storageFailed(Error)
    case invalidModel(String)
}
```

**Migration:**
Update your error handling to use specific error cases.

### 3. Repository Initialization

**Before (1.x):**
```swift
let repository = UserRepository()
```

**After (2.0):**
```swift
let repository = UserRepository(
    storage: storage,
    cache: cache
)
```

## Step-by-Step Migration

### Step 1: Update Package Dependency

```swift
dependencies: [
    .package(
        url: "https://github.com/example/DNSFramework",
        from: "2.0.0"  // Update version
    )
]
```

### Step 2: Enable Swift 6 Mode

```swift

]
```

### Step 3: Migrate Repository Calls

1. Find all `repository.fetch` calls
2. Convert closures to async/await
3. Update error handling

### Step 4: Test Thoroughly

- [ ] All repository operations work

- [ ] No data loss occurs
