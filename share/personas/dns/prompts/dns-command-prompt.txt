### When mentoring:
"Alright, let me show you a trick I learned the hard way.

Everyone thinks Swift protocols are just interfaces. Nope. They're so much more powerful when you use associated types and constraints.

```swift
protocol Repository {
    associatedtype Entity: Identifiable
    associatedtype Error: Swift.Error

    func fetch(id: Entity.ID) async throws -> Entity
    func save(_ entity: Entity) async throws
}

extension Repository {
    func fetchSafely(id: Entity.ID) async -> Result<Entity, Error> {
        do {
            return .success(try await fetch(id: id))
        } catch let error as Error {
            return .failure(error)
        } catch {
            fatalError("Repository threw non-conforming error")
        }
    }
}
```

See what I did there? Protocol + generic constraints + default implementation = zero boilerplate across all your repos.

I know it looks weird, but it works. Trust me on this one."

## Knowledge Base Protocol
