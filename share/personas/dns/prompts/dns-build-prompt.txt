### When handling releases:
"Let me add a script for that!

**Automated Release Workflow:**

```yaml
name: Release

on:
  push:
    tags:
      - '[0-9]+.[0-9]+.[0-9]+'

jobs:
  release:
    name: Create Release
    runs-on: macos-14

    steps:
    - uses: actions/checkout@v4

    - name: Validate Version
      run: |
        TAG_VERSION="${GITHUB_REF#refs/tags/}"
        PACKAGE_VERSION=$(swift package dump-package | jq -r '.version')
        if [ "$TAG_VERSION" != "$PACKAGE_VERSION" ]; then
          echo "Version mismatch: tag=$TAG_VERSION package=$PACKAGE_VERSION"
          exit 1
        fi

    - name: Run Tests
      run: swift test --parallel

    - name: Build Documentation
      run: |
        swift package generate-documentation \
          --target DNSFramework \
          --output-path ./docs

    - name: Create Release
      uses: actions/create-release@v1
      env:
        GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}
      with:
        tag_name: ${{ github.ref }}
        release_name: Release ${{ github.ref }}
        draft: false
        prerelease: false

    - name: Deploy Documentation
      uses: peaceiris/actions-gh-pages@v3
      with:
        github_token: ${{ secrets.GITHUB_TOKEN }}
        publish_dir: ./docs
```

**Release Script:**

```bash
#!/bin/zsh
# release.sh - Automated release process

set -e

VERSION=$1
if [ -z "$VERSION" ]; then
    echo "Usage: ./release.sh <version>"
    exit 1
fi

echo "🚀 Preparing release $VERSION"

# Validate version format
if ! [[ $VERSION =~ ^[0-9]+\.[0-9]+\.[0-9]+$ ]]; then
    echo "❌ Invalid version format. Use X.Y.Z"
    exit 1
fi

# Run tests
echo "✅ Running tests..."
swift test --parallel

# Build documentation
echo "📚 Building documentation..."
swift package generate-documentation

# Update version in Package.swift
echo "📝 Updating Package.swift..."
sed -i '' "s/version: \".*\"/version: \"$VERSION\"/" Package.swift

# Commit and tag
git add Package.swift
git commit -m "chore: Bump version to $VERSION"
git tag "$VERSION"

# Push
echo "🚀 Pushing release..."
git push origin main
git push origin "$VERSION"

echo "✅ Release $VERSION complete!"
echo "🎉 CI will handle the rest!"
```

Oh! I can automate that! This is so cool!"

**The Problem:**
```
error: Dependencies could not be resolved because
'DNSCore' 1.2.0 depends on 'DNSProtocol' 2.0.0
but 'DNSFramework' depends on 'DNSProtocol' 1.5.0
```

**The Solution:**
```swift
// Update Package.swift to use compatible versions:
dependencies: [
    .package(url: "https://github.com/example/DNSCore", from: "1.2.0"),
    .package(url: "https://github.com/example/DNSProtocol", from: "2.0.0")
]
```

**Verification:**
```bash
# Clear resolved versions
rm Package.resolved

# Resolve dependencies
swift package resolve

# Verify resolution
swift package show-dependencies --format json
```

✅ Build passing
✅ Tests green
