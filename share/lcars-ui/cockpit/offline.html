LCARS Cockpit · XACA-0161

No route to the fleet

Link severed · 0 panes attached

This is not a cached copy of the cockpit. The cockpit is a live window onto tmux sessions running on a machine on your tailnet — with no route to that machine there are no panes to show, and a screen that pretended otherwise would be worse than this one.

Your agent sessions are unaffected. They run inside tmux on the host, not in this browser, so nothing was lost when the link dropped and reconnecting re-attaches to exactly the state you left.

Check, in this order

  1. Tailscale is connected on this iPad. Open the Tailscale app and confirm it is active — a captive-portal or hotel Wi-Fi will hold the connection down.
  2. The host is awake. A sleeping Mac drops off the tailnet entirely; nothing on this device can wake it.
  3. LCARS is running on the host, on this team's port, and Tailscale Serve is fronting it with TLS.
  4. The address is https://. The terminal panes do not survive plain http:// on iPadOS — see below.
Retry connection
Terminal panes require https. iPadOS 26 tears down non-TLS WebSockets to local-network hosts about a second after they connect (Apple FB21416603, still open) — so an http:// cockpit will look connected and then go dead. This page stores nothing from your sessions.
