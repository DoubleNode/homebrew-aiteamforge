Usage Instructions

To add tooltips to any avatar image:

<img src="/avatars/academy_reno_avatar_thumb.png"
     class="lcars-avatar"
     data-persona="reno"
     alt="Reno">

Just add two things:

  • class="lcars-avatar" - Enables hover behavior
  • data-persona="key" - Persona key from LCARS.personas.metadata

The tooltip system handles everything else automatically!
